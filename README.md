# Li Guoqiu — Personal Site

This is a static personal portfolio designed for GitHub Pages. All editable page content is stored in [`content/site.json`](content/site.json).

## Publish with GitHub Pages

1. Create a new GitHub repository named `YOUR-GITHUB-USERNAME.github.io` for the shortest URL, or use any repository name for a project URL.
2. Upload the **contents** of this folder to the repository root, including `index.html`, `styles.css`, `script.js`, `content/`, and `.nojekyll`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main`, then select `/(root)` and save.
5. Wait for the deployment notice. The site will be available at:
   - `https://YOUR-GITHUB-USERNAME.github.io` for a user-site repository; or
   - `https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/` for a project repository.

## Edit content

1. Open `content/site.json` in your GitHub repository.
2. Select the pencil icon (**Edit this file**).
3. Update profile fields, News entries, Projects, or Experience & Education.
4. Select **Commit changes**.
5. GitHub Pages rebuilds the page automatically. Refresh the public page after the deployment finishes.

`content/site.json` must remain valid JSON. Keep quotation marks and commas intact when editing. You can use GitHub's built-in editor or edit the file locally in VS Code.
